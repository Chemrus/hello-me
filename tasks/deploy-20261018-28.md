# Задание 28 — СРОЧНО: переводы раздела Хошимина отдают 404 (18.10.2026)

Код: ветка `claude/sections` в `Chemrus/letfind-wp`, коммит **19adc91**, один файл — `mu-plugins/lf-gtranslate-url-fix.php`. Выкладывать отдельно и сразу, не дожидаясь заданий 26 и 27.

## Что сломано

В переводах `/vi/`, `/uz/`, `/pt/` весь раздел Хошимина — страница города и все карточки `/vietnam/hochiminh/…` — отдаёт 404.

Прокси GTranslate запрашивает у сайта адрес с кириллической «с» в слове hochiminh (заголовок ответа `x-gt-origurl: /vietnam/ho%D1%81himinh/…`), такого адреса на сайте нет. Другие города и языки в выборке из 39 страниц × 8 языков отдают 200.

## Что меняется

`lf-gtranslate-url-fix.php` уже исправляет похожие подмены (activities → aktivnosti). Теперь он ещё заменяет кириллические буквы-двойники (с, а, е, о, р, х, у, к…) обратно на латинские. Касается только сегментов, где кириллица смешана с латиницей, и только запросов от GTranslate (заголовок `X-GT-Lang`). На русский сайт и настоящие кириллические адреса не влияет.

## Шаги

1. Бэкап серверного файла в `/home/customer/backup-20261018-t28/`. Сверить с репозиторием: если серверный отличается от версии до `19adc91` — стоп и diff.
2. Выложить файл из `19adc91`, `php -l`.
3. Сбросить кэш SiteGround для `/vietnam/hochiminh/*`.
4. Сбросить кэш переводов GTranslate для `vi`, `uz`, `pt` (в my.gtranslate.io, раздел кэша), если доступ есть. Если нет — написать: 404 мог закэшироваться у них.
5. Проверить (код ответа должен быть 200, заголовок страницы — не «Страница не найдена»):
   ```
   for l in vi uz pt en; do for p in /vietnam/hochiminh/ /vietnam/hochiminh/food/bars/snuffbox/ /vietnam/hochiminh/activities/concerts/eifman-ballet-eugene-onegin-ho-chi-minh-city/ /vietnam/hochiminh/attractions/offices/saigon-central-post-office/; do curl -s -o /dev/null -w "%{http_code} $l$p\n" "https://letfind.me/$l$p"; done; done
   ```

6. Ошибок PHP в логе нет.

my.gtranslate.io → URL translation: найти и удалить пары, где `hochiminh` переведён с кириллической «с», для vi, uz, pt (и проверить другие языки). После этого заплатка станет не нужна, но вреда не принесёт.
