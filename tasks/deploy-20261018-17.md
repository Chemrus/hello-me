# Задание 17 — новый блок отзывов вместо старой формы комментариев (18.10.2026)

Ветка `claude/sections` в `Chemrus/letfind-wp`, коммит **5a9b5aa** (edc9ea2 — блок отзывов, 5a9b5aa — виджеты города) (после задания 16; можно выкладывать вместе с ним).
Файлы: `mu-plugins/lf-ds.php`, `mu-plugins/lf-voice.php`, `mu-plugins/lf-voice/comments.php`.

## Зачем

Владелец увидел старую форму WordPress («Оставить комментарий», имя, email, сайт) на
/vietnam/festivals/russian-cultural-events-vietnam-2026-2027/. Блок «Ваш опыт по материалу» (lf-voice) включался только для
hints, laws, guides, cities, articles, culture, history, blogs, notes. Старая форма стоит ещё на 16 типах.

## Что меняется

- `lf-ds.php`: фильтр `lfv_types` добавляет festivals, attractions, billboard, news, brief, digital, business, locals, faq,
  real_estate, job, reviews, prices, sales, press-release. Товары магазина (product) не трогаем — там отзывы WooCommerce.
- `lf-voice.php`: признак «блок уже выведен» — в `$GLOBALS['lfv_done']` вместо static (нужен шаблону комментариев).
- `lf-voice/comments.php`: если шаблон записи не вызвал the_content в цикле и блок не вывелся после текста — он выводится
  на месте старой формы. Опубликованные комментарии по-прежнему показываются списком.

## Ещё: виджеты на странице города (`lf-ds.php`, коммит 5a9b5aa)

«Погода» и «Сейчас во Вьетнаме» на странице города: фоны #FEFFE8 / #FFF3ED и чёрная рамка → цвета палитры.
