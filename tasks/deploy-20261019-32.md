# Задание 32 — блок «Сегодня во Вьетнаме» (19.10.2026)

Код: ветка `claude/sections` в `Chemrus/letfind-wp`, коммит **70f44bc**, два новых файла:
- `mu-plugins/lf-history-days.php` — шорткод `[lf_today_history]`;
- `mu-plugins/lf-history-days-data.php` — данные. Файл сгенерирован из `hello-me/data/history-days.csv` скриптом `tools/build-history-days.py`, руками не править.

## Что это

База «День в истории» для ЕПИ (решение владельца 19.10). Блок показывает:
- что было в этот день;
- что будет на этой неделе (7 дней вперёд).

Берутся только проверенные даты. Если событий нет ни сегодня, ни на неделе, блок не выводится.

## Шаги

1. Выложить оба файла, `php -l`.
2. Проверить шорткод на черновике: `wp post create --post_type=page --post_status=draft --post_title=lfhd-test --post_content='[lf_today_history]' --porcelain`. Открыть предпросмотр под администратором: блок «📜 Сегодня во Вьетнаме», ниже «На этой неделе» — 20 октября «День вьетнамских женщин», 26 октября. Черновик удалить.
3. Написать основной сессии «выложено». Блок на «Афишу на сегодня» основная сессия поставит сама: если поставить шорткод раньше выкладки, на странице будет виден текст `[lf_today_history]`.
4. Ошибок PHP в логе нет.

## Откат

Удалить оба файла. Если шорткод уже стоит на странице, он превратится в текст — тогда убрать его из страницы 5300.
