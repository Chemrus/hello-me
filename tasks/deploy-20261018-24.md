# Задание 24 — старые «технические» адреса записей: 301 вместо 404 (18.10.2026)

Код: ветка `claude/sections` в `Chemrus/letfind-wp`, коммит **7585450**, файл `themes/letfind/native-redirect.php`.

## Зачем

Владелец нашёл в Яндексе адрес `/activities/zakrytie-vystavki-fonda-tvorcheskogo-naslediya-hudozhnikov-novikovyh-v-hanoe/`, он отдавал 404.
Это старый адрес вида `/<тип записи>/<заголовок латиницей>/`: запись с таким заголовком или удалили, или переименовали.
Для этого одного адреса основная сессия уже завела редирект 301 в AIOSEO (id 408). Таких адресов в индексе может быть больше,
а журнал 404 AIOSEO пуст, поэтому закрываем весь класс кодом.

## Что меняется

В `native-redirect.php` добавлен третий обработчик (`template_redirect`, приоритет 3). Срабатывает только на 404 вида `/<зарегистрированный тип>/<slug>/`:
1. Ищет опубликованную запись этого типа со старым slug `_wp_old_slug` = slug → 301 на её адрес.
2. Иначе ищет запись этого типа, у которой заголовок, пропущенный через `sanitize_title()` (латиница), равен slug → 301. Индекс заголовков хранится в транзиенте `lf_title_slugs_<тип>` на 12 часов.
3. Иначе для `activities` — 301 на `/vietnam/billboard/`.
4. Иначе остаётся 404, как сейчас.

Первые два обработчика файла (задание 21) не меняются.

## Шаги

1. Бэкап `themes/letfind/native-redirect.php` в `/home/customer/backup-20261018-t24/`. Сверить серверный файл с коммитом `94f9612`: при расхождении — стоп и diff.
2. Выложить файл из `7585450`, `php -l`.
3. **AIOSEO → Редиректы → Настройки → «Отслеживать изменения адресов»:** включить для всех типов записей и для корзины. Тогда при смене адреса или удалении записи AIOSEO сам создаёт редирект. Владелец согласен.
4. Сбросить кэш SiteGround для адресов из проверки.
5. Проверить (`curl -sI`, смотреть код и `location`):
   - `/activities/zakrytie-vystavki-fonda-tvorcheskogo-naslediya-hudozhnikov-novikovyh-v-hanoe/` → 301 на `/vietnam/hanoi/activities/concerts/novikov-art-exhibition-hanoi/` (через AIOSEO, как и было).
   - `/activities/teatr-baleta-borisa-ejfmana-evgenij-onegin-v-hanoe/` → 301 на `/vietnam/hanoi/activities/concerts/eifman-ballet-eugene-onegin-hanoi/` (совпадение по заголовку).
   - `/activities/kakoe-to-udalennoe-meropriyatie/` → 301 на `/vietnam/billboard/`.
   - `/objects/takogo-net-12345/` → 404 (не мероприятие — остаётся 404).
   - `/activities/gba-oktoberfest-hanoi-2026/` → 301 на настоящий адрес, как и раньше (первый обработчик).
   - `/vietnam/billboard/`, любая карточка ресторана, `/?p=17103` — работают как раньше.
   - Ошибок PHP в логе нет.

## Откат

Вернуть файл из бэкапа, сбросить кэш. Настройку отслеживания в AIOSEO можно оставить включённой.
