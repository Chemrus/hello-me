# Задание 27 — открыть кабинет всем на сайте Вьетнама (18.10.2026)

Владелец: «ставим кабинет в прод, а потом если что правим точечно».

Кабинет — плагин `letfind-cabinet` (на сервере версия 0.32.2, копия в `Chemrus/letfind-wp`, ветка `sync/theme-20261018-2`). Сейчас он в **тихом режиме**: его видят только администраторы и тестировщики. Открыть — значит поставить галочку «Настройки → Кабинет LetFind → Открыть всем» **только для сайта Вьетнама**. Код не меняется.

Главный риск — кэш: если SiteGround отдаст чужую личную страницу из кэша, человек увидит чужие имя, почту и места. Поэтому открываем только после проверки ниже. Если проверка не прошла — стоп и отчёт.

## Шаги

0. Сначала выложено задание 31 (закрытые профили): без него по `/account/?user=<номер>` видны имена людей.

1. **Кэш.** В SG Optimizer исключить из кэша `/user/*`, `/account/` и страницу с шорткодом `[lf_cabinet]`: `wp post list --post_type=page --s='[lf_cabinet]' --fields=ID,post_name,url`. Прислать список исключений.
2. **Проверка кэша** по разделу README плагина «Проверка кэша перед „Открыть всем“», целиком:
   - двое тестировщиков, А (город Дананг) и Б (остров Фукуок), плюс гость; три отдельных окна браузера;
   - А заполняет анкету и открывает кабинет 2–3 раза подряд, затем тот же адрес открывают Б и гость;
   - у Б и гостя не должно быть ничего от А: ни имени, ни почты, ни города, ни «Моих мест», ни отмеченных кнопок «Хочу посетить» и «Был(а)» на странице места;
   - повторить на `/en/…` и после выхода и повторного входа;
   - у ответа страницы кабинета — заголовок `Cache-Control: no-cache…`.
   Прислать результат по каждому пункту и скриншоты кабинета у Б и у гостя.
3. **Вход в один клик** (код уже на сервере — `includes/auth.php`; бот @letfindmebot, токен и ключи Google заданы; выключен только переключатель «для всех», поэтому на фронте кнопок нет — замечание владельца 19.10).
   Проверка до включения — в окне инкогнито на телефоне по адресу `https://letfind.me/account/?login=preview` (кнопки видны только по этой ссылке):
   - **Telegram:** «Войти через Telegram» → подтверждение в Telegram → вернулись на `/account/` уже вошедшим. Если ошибка «Bot domain invalid» — в @BotFather у @letfindmebot: `/setdomain` → `letfind.me`.
   - **Google:** «Войти через Google» → выбор аккаунта → вернулись вошедшим. Проверить **аккаунтом, которого нет в списке тестировщиков** Google Cloud: если Google пишет «Доступ заблокирован» / «приложение не прошло проверку» — в Google Cloud → OAuth consent screen (Google Auth Platform → Audience) нажать «Publish app» (статус In production). Для областей openid, email, profile проверка Google не нужна. Название приложения на экране согласия — LetFind, логотип и ссылка на политику — по желанию.
   - **Почта:** «Войти по почте» → письмо пришло (отметить, если в «Спаме») → по ссылке кнопка «Войти» → вошли.
   - После входа каждым способом: в «Пользователях» новый аккаунт, имя подтянулось; повторный вход тем же способом — тот же аккаунт, а не новый.
   Прислать, что работает и что нет. Секреты (токен, Client secret) в отчёт не писать.
4. **Пробный тур тестировщика Б** (остров Фукуок, турист, даты поездки): анкета; «Для вас»; «Хочу посетить» на 2–3 местах; «Был(а)» на одном месте; чек-лист острова с картой; «Мои места»; новости. Прислать скриншоты на 390 px в светлой и тёмной теме и всё, что выглядит сломанным или пустым.
5. **Только если шаги 2–3 чистые:**
   - галочка «Открыть всем» (Настройки → Кабинет LetFind) — для сайта Вьетнама. Узбекистан и другие страны не трогать;
   - на главном сайте сети: Настройки → «Вход в кабинет» → «Включить вход для всех» → Сохранить. Способ, который на шаге 3 не заработал, — выключить в этих же настройках (у Telegram и Google — стереть ключ галочкой «удалить» нельзя без владельца: лучше прислать, что не работает, и включить остальные).
   - Проверить в инкогнито без `?login=preview`: на `/account/` блок «Войти в один клик» с рабочими кнопками.
6. Сбросить кэш SiteGround для `/account/`, `/user/` и страниц мест острова Фукуок.
7. Сутки смотреть лог ошибок PHP; через сутки прислать: ошибки (если есть), сколько человек прошли анкету, сколько отметок «Хочу посетить» и «Был(а)» (таблица `wpe4_lf_cab_relations`).

## Откат

Снять галочку «Открыть всем» — кабинет снова видят только администраторы и тестировщики. Анкеты и отметки людей сохраняются. Вход в один клик — снять «Включить вход для всех»: кнопки останутся только по `?login=preview`, созданные аккаунты сохранятся.
