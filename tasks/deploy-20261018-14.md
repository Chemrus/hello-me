# Задание агенту деплоя, 18 октября 2026 (четырнадцатое): цвета дизайн-системы, шаг 1

Цель: один фиолетовый и один цвет текста по всему сайту. На сайте сейчас пять оттенков фиолетового (в том числе опечатка #7B4BEC — 104 раза) и семь оттенков чёрного для текста. Меняются только HEX-значения в стилях — разметка и логика модулей не трогаются.

**Делается скриптом на сервере, а не выкладкой файлов из ветки** — модули на сервере могут быть новее нашей выгрузки, скрипт меняет их текущие версии.

1. Скопировать `tasks/ds-colors-20261018.sh` в `wp-content/`.
2. Пробный проход: `bash ds-colors-20261018.sh` — ничего не меняет, печатает число замен по файлам. **Прислать вывод** (у нас на выгрузке — 236 замен в 58 файлах).
3. Если цифры близки — `bash ds-colors-20261018.sh --apply`: делает резервную копию (tar в wp-content), заменяет, проверяет каждый PHP-файл (`php -l`). Прислать хвост вывода.
4. Сбросить кэш SiteGround.

Что заменяется:
| Было | Стало |
|---|---|
| #7B4BEC, #794AE6 | #7B4AEC (основной фиолетовый) |
| #592FBC, #5A2FC4, #6629DE | #5B34C9 (тёмный фиолетовый — наведение, текст-акцент) |
| #2C2C32, #333333, #222222, #323036, #292727, #151515, #0D0D0D | #2C2C31 (цвет текста) |

Не трогается: карточка заведения (`page-object-v2.php`, зелёная гамма — решение владельца), короткие #333/#222 (рамки тёмной темы), `*.min.css`, резервные копии.

Проверить после: главная, /vietnam/, /vietnam/danang/, любая инструкция, афиша — фиолетовые кнопки одного цвета, тексты читаются, тёмная тема без изменений. Откат: `tar -xzf ds-colors-backup-….tar.gz` в wp-content.

Ветка `claude/sections` (коммит 58d3863) уже содержит те же замены, чтобы последующие выкладки файлов из неё не вернули старые цвета. Плюс в `lf-ds.php` — переменные дизайн-системы на всех страницах (`--lf-brand`, `--lf-ink`, `--lf-r-md`…): выложить `lf-ds.php` из этой ветки вместе с шагом 3.
