# Задание 30 — кабинет 0.33.0: «Где живёте» и предложения по близости (19.10.2026)

Код: ветка `claude/sections` в `Chemrus/letfind-wp`, коммит **e9229bd**, плагин `plugins/letfind-cabinet` (0.32.3 → 0.33.0).

## Зачем

Владелец: «мэтчить предложения в сервисе по ближайшему расположению».

## Что меняется (5 файлов плагина + README)

| Файл | Что |
|---|---|
| `includes/profile.php` | Новое поле анкеты `lf_cab_home` — ключ точки «Я здесь» своего города; сохраняется, только если точка есть у выбранного города. Добавлено в `lf_cabinet_profile_keys()`, значит удаляется вместе с анкетой («Удалить мои ответы», удаление личных данных). |
| `includes/render.php` | В анкете, шаг с датами — «Где живёте или остановились?»: выпадающий список точек по городам, точки других городов скрыты переключателем города. Необязательно. |
| `includes/offers.php` | Если точка задана, «Предложения для вас»: лично назначенные и «Хочу посетить» сверху, дальше купоны по расстоянию до заведения, без координат — после. Под заголовком — «📍 650 м от вас», в «Почему» — «рядом с вами» (до 5 км). Скидки (`sales`) — ниже, как раньше. Без точки — всё как сейчас. |
| `includes/here.php` | «Я здесь»: точка из анкеты выбрана сразу и ответ приходит без нажатия. Точки острова Фукуок переименованы под 9 страниц районов сайта: `duongdong`, `longbeach`, `onglang`, `sonasea`, `baidai`, `anthoi`, `baikhem`, `hamninh` плюс пляжи `sao`, `ganhdau`, `rachvem` (раньше были `grandworld`, `south`, `khem`). Сохранённых ключей старых точек нет — точки выбирались только на один запрос. |
| `letfind-cabinet.php` | Версия 0.33.0. |

## Шаги

1. Бэкап папки плагина на сервере. Сверить пять файлов с серверными: если серверные отличаются от версии 0.32.3 в ветке — стоп и diff.
2. Если на сервере можно запустить тесты плагина (`bash tests/run.sh`) — запустить на копии, прислать итог. Не получается — написать.
3. Выложить файлы, `php -l`.
4. Проверить тестировщиком Б (остров Фукуок, турист):
   - анкета: на шаге с датами есть «Где живёте или остановились?»; при городе Фукуок в списке только точки острова; выбрать «Лонг Бич», сохранить;
   - «Я здесь»: «Лонг Бич · вы живёте здесь» выделен, список рядом пришёл сам;
   - «Предложения для вас»: у купонов с координатами заведения — «📍 … от вас», ближние выше. Если купонов на острове нет — завести тестовый купон на заведение с координатами (например, Lucia в Sunset Town, 9283) и на заведение на Лонг Бич; ближний должен встать первым; потом удалить их;
   - поменять город в анкете на Дананг — точка острова сбрасывается;
   - «Удалить мои ответы» — поле тоже удаляется.
   Скриншоты на 390 px, светлая и тёмная тема.
5. Ошибок PHP в логе нет.

## Откат

Вернуть папку плагина из бэкапа. Поле `lf_cab_home` у пользователей можно оставить — старая версия его не читает.
