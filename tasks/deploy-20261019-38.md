# Задание 38 — вкладки [lf_tabs]: текст каждой следующей вкладки уходил ниже (19.10.2026)

Код: ветка `claude/sections` в `Chemrus/letfind-wp`, коммит **e85d18e**, один файл `mu-plugins/lf-tools.php`. Можно выкладывать в любом порядке с другими заданиями: этот файл в них не меняется.

## Зачем

Владелец: «текст с каждой новой вкладкой уходит всё ниже и ниже». WordPress (wpautop) ставит `<br />` между вкладками, если шорткоды `[lf_tab]` стоят в тексте с новой строки. Скрытые вкладки не видны, а `<br />` между ними видны: перед второй вкладкой одна пустая строка, перед седьмой — шесть. В шорткоде `lf_tabs` теперь эти `<br />` убираются.

Статья /hints/beach-access-vietnam-hotel-rights/ (18909) уже поправлена в тексте: шорткоды в одну строку. Код нужен для остальных материалов с вкладками.

## Шаги

1. Бэкап `mu-plugins/lf-tools.php` в `/home/customer/backup-20261019-t38/`. Сверить серверный файл с коммитом `ec4efe3`: при расхождении — стоп и diff.
2. Выложить файл, `php -l`.
3. Найти материалы с вкладками: `wp db query "SELECT ID, post_type, post_name FROM wp_posts WHERE post_status='publish' AND post_content LIKE '%[lf_tab %'"`. На двух из них сбросить кэш и проверить: в HTML между `</section>` и `<section class="lftb-pane"` нет `<br />`; при переключении вкладок текст начинается сразу под кнопками.
4. Ошибок PHP в логе нет. Прислать список материалов из шага 3.
