# hello-me — память проекта LetFind

- `wp.py` — работа с letfind.me через REST (см. README). Пароль приложения никогда не выводить.
- `tasks/` — задания агенту деплоя (сервер letfind.me).
- `memory/` — решения владельца, которые нужно помнить между сессиями:
  - `memory/epi.md` — ЕПИ, матрёшка: базовый → усиленный → профессиональный. Сейчас работаем на базовом.
  - `memory/lk-plan.md` — план переноса макета кабинета в настоящий (плагин), по этапам.
  - `memory/lk.md` — личный кабинет: пилот — Фукуок, модель «польза → доверие → список → продажи», что есть в данных.
  - `memory/pq-content.md` — контент острова Фукуок к открытию кабинета: правила (без копирования чужих текстов), карточки мест, что сделано.
  - `memory/sales.md` — раздел «Новинки и скидки» (/sales/): поля записи, правила наполнения.
  - `memory/epi-signals.md` — журнал сигналов ЕПИ: что пришло, что поправили на сайте, когда перепроверить.
- Темы материалов (`lf_theme`, «Культура и традиции → Праздники» = id 603) ставятся через REST: `POST wp/v2/<тип>/<id>` с `{"lf_theme": [...]}`. При публикации ставить сразу, по образцу соседних материалов.
- `data/history-days.csv` — «День в истории»: исторические и культурные даты для ЕПИ. Пишем туда всё датированное, что попадает на сайт или приходит в чат (см. `memory/epi.md`).
