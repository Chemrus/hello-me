# «Моя поездка» — лёгкий кабинет по личной ссылке (05.11.2026)

Решение владельца 05.11: личный кабинет в задуманном виде «не впишется»; гостю в Telegram (личка) шлём ссылки и подборки, а всё его — на одной странице портала. Пробуем **с консьержем вручную (без бота)**, страница **только по ссылке, закрыта от поиска, без входа**, пилот — **Фукуок**. Разбор «вписываемости» — `memory/funnels.md` (05.11).

- Код: `letfind-wp/mu-plugins/lf-my-trip.php` (префикс `lftrip_`; `lfmy_` занят «Моим Вьетнамом» в lf-my.php). Тип записи `lf_trip` — админка «Гости (поездка)».
- Адрес гостя: `/vietnam/trip/<код 14 знаков>/` (`/my/` занят — раздел страны). noindex (заголовок + AIOSEO), без кэша.
- **Консьерж:** новый гость → имя (первое слово — обращение), контакт (@ник / телефон), куда писать (Telegram/WhatsApp/Zalo), даты, район, «что любит», заметка для команды. «Подборка»: строки `ссылка | заметка для гостя`, строка `# Заголовок` — новый раздел. Быстрее: на любой странице сайта верхняя панель «➕ В поездку гостя» → гость (ссылка добавится в конец подборки, заметку дописать в админке). Справа — личная ссылка, готовое сообщение (Скопировать), «Открыть чат», счётчик открытий и сохранённого.
- **Страница гостя:** приветствие, даты, район, «что любит», «Спросить консьержа»; море сегодня у его берега (lf-sea); подборки карточками с заметками; «🎟 Мои купоны» — купоны (ACF coupon-group) мест из подборки и сохранённого; «🗓 Мои брони и заявки» — lf_lead за 60 дней с тем же контактом (телефон — последние 9 цифр, или @ник); «♡ Сохранённое» с «Убрать».
- **♡ В мою поездку:** после первого открытия страницы браузер ставит cookie `lftrip` (сервер Set-Cookie срезается кэшем — ставим из JS); на страницах мест, экскурсий, акций, событий кнопку рисует браузер (страницы в кэше Cloudflare), проверка/сохранение — admin-ajax `lftrip_state` / `lftrip_save`. Кнопка по центру внизу (слева — окно cookie и «Сейчас во Вьетнаме»).
- Метрики для теста «вписываемости»: открытия (`_lftrip_views`, `_lftrip_last`, не считаем админов), сохранённое (`_lftrip_saved`), событие GA `my_trip_save`.
- Тестовый гость: «Анна (тест)», id 20140 — https://letfind.me/vietnam/trip/knatywpjnjbp4b/ (migrate my-trip-demo). Перед реальным тестом можно удалить.
