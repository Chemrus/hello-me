# ЕПИ — журнал сигналов

Каждый сигнал записываем, даже если он не подтверждён.
Формат записи:
- **когда:** дата;
- **потребность:** одна из четырёх;
- **откуда:** источник, без имён людей;
- **что говорят:** суть сигнала;
- **что сделали:** где поправили на сайте;
- **перепроверить:** дата (визы и правила — через 14 дней).
