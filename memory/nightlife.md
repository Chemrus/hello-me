# Ночная жизнь — пересборка (пилот: Фукуок)

- Владелец 26.10.2026: «ночная жизнь хромает… подавать заведения, афиши, рассказ о заведении, что проходит; календарь праздников разных национальностей; по районам, по стилю музыки и заведений; чтобы по ночной жизни знали, что идти к нам; всё технично перетекало в ЛК». Решения: **пилот — Фукуок**, **сначала макет**, профили заведений публикуем **«по данным заведения»** (без отдельной проверки).
- **Аудит 26.10:** страницы /vietnam/<город>/nightlife/ (код mu-plugins/lf-nightlife/hub-v2.*, lf-nightlife-hub.php, поля lf-nightlife-fields.php). Фукуок: 32 заведения, подтверждённая программа только у The Rabbit Hole (живая музыка ср–пт 20–22); у остальных — огромная карточка с заглушкой «Ближайшая программа пока не подтверждена» (Дананг 42, Нячанг 22, Ханой 21, Хошимин 11). Музыка/формат — только у событий (lf_nl_music), не у заведения; район — свободный текст (lf_nl_area), не наши районы; регулярных вечеров нет.
- **Макет:** https://claude.ai/artifact/GFNBkvsb8QQSBZN2wem5Lm (данные — настоящие 32 заведения из карточек; стили/музыка/«обычно» — по их описаниям; сборка: scratchpad build_nl.py + nl-mock.tpl.html). Что в нём (версия 2, 26.10 — владелец: «в чём разница между „где я живу“ и „где“?», «слишком темно — совместить тёмный с белыми блоками»): «Когда» · «Какой вечер» (закат и бич-клуб, живая музыка, клуб и DJ, руфтоп и коктейли, паб и спорт, танцы у моря, тихо и красиво) · одна строка «Где искать» (📍 Рядом со мной до 15 мин / Весь остров / район); дом — не фильтр, а точка отсчёта: строка «🏠 Я живу: … · изменить» (тот же «мой район» сайта и кабинета; «Рядом со мной» без дома открывает выбор). Вид: светлая страница, тёмные шапка, «Вечер по часам» и блок для владельцев; выбор, карточки, календарь — белые → «Вечер по часам» (закат 17:30–19:30 → музыка 20–23 → клубы после 23) → компактные карточки (≈ N мин от дома, стиль, музыка, «обычно / сегодня», фишки, ♡ / 🎟️ Иду) → «Праздники и тематические вечера» (Хэллоуин, Дивали 8.11, День учителя 20.11, День благодарения 26.11, Рождество, Новый год, Тет 6.02.2027 — сверить, 23.02/8.03, День св. Патрика; «где» — пример) → блок «Вы владелец? анкета» → нижняя панель «Мои вечера» (сохранено и «Иду», вкус, напоминание в Telegram, друзья) = кабинет.
- **Дальше после одобрения макета:** 1) поля заведения: стиль, музыка, регулярная программа (дни, время), «кто ходит»; район — из нашей системы (lfpd/lfmd); 2) новая страница хаба Фукуока по макету (без заглушек); 3) календарь праздников (lf_event + аудитория); 4) кабинет: «Мои вечера», напоминания, вкус в кубике; 5) раздел «Ночь» в анкете заведения (for-venues).
- **26.10 — ВЫЛОЖЕНО (main 154530d):** владелец «устанавливаем макет». https://letfind.me/vietnam/phuquoc/nightlife/ (страница 18923, `[lf_nightlife city="phuquoc"]`) рендерит `mu-plugins/lf-nightlife/hub-v3.php` (`lfnl_render_v3`); выбор версии — `lfnl_hub()` в lf-nightlife-hub.php по `lfnl_v3_cities()` (откат — вернуть пустой массив); другие города — hub-v2.
  - Профили — `lfnl_v3_profiles()` по id места: стили (beach live club rooftop pub dance quiet), музыка, «по данным заведения», слот (sunset/live/club), дни (0 = пн; только Ando и Cheeky Traveller — «каждый день» по их описаниям). Новое место без профиля попадает само (стиль по разделу clubs/karaoke/bars, текст — описание карточки).
  - Программа с датой — только `lfnl_events()` (проверенные расписания и события); «Иду» — только у событий с карточкой (`lf_cab_event_go`). «♡ Сохранить» = «Хочу посетить» в кабинете (`lf_cab_place_set`); у гостя — localStorage `lfnl_saved`, после входа переносится в кабинет. Личное — AJAX `lfnl_my`.
  - Район и «≈ N мин от дома» — общий «мой район» (`window.lfMy`, выбор — `data-lfmd-pick`). Данные кэшируются transient `lfnl_v3_phuquoc` на 1 ч (сброс — сохранение места/события).
  - Праздники — `lfnl_v3_holidays()` (только уверенные даты; «где отметить» не показываем, пока заведения не подтвердят). Тет 2027 — 6 февраля.
  - Мобильная нижняя панель «Мои вечера» не сделана фиксированной (конфликт с плавающими кнопками сайта) — кнопка «♡ Мои вечера» над списком. Напоминания в Telegram и друзья — следующий этап (кабинет).
  - События: nl_filter, nl_save, nl_go, nl_more.
  - 26.10, владелец «оставить карусели, но показать «ещё →»»: у каждой карусели (главы и праздники) — «1–3 из 13», «‹» и «Ещё →», правый край затухает, пока есть что листать.
