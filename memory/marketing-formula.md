# Авторская формула маркетинга владельца LetFind

Записано 25.10.2026 со скрина таблицы владельца. Это авторская формула. Её используем как каркас для всех воронок: `memory/funnels.md` разбирает LetFind по этим столбцам. Столбцы идут **слева направо, это последовательность**. Стрелки в таблице ведут от «Позиционирования» через «Соц. доказательства», «УТП», «Отстройку», «Лид-магнит» и «Оффер» к «Сервису»: каждый шаг опирается на предыдущий.

| № | Столбец | Что в него входит (строки таблицы владельца) |
|---|---|---|
| B | **Цели и ограничения** | До выбора каналов зафиксировать цель: число заявок, продаж, повторных визитов или выручка. · Нужны допустимая стоимость привлечения клиента, средний чек, валовая маржа и ценность клиента за всё время отношений. · Здоровая экономика: стоимость привлечения клиента — не больше трети его пожизненной ценности. |

## Лестница продуктов (правило владельца)

Минимум три продукта: **один для рекламы, один для продажи и один для зарабатывания денег.**

| Ступень | Что это |
|---|---|
| **Lead magnet** | бесплатный или очень дешёвый продукт, привлекающий лидов |
| **Tripwire** | продукт «за один доллар», за который клиент платит вам первые деньги |
| **Penny product upgrade** | продукт «за один цент» в придачу к первой покупке |
| **Main product** | продукт, на котором вы зарабатываете основную прибыль |
| **Bonus** | бесплатный продукт, усиливающий основной |
| **Profit maximizer** | продукт в дополнение к основному, увеличивает сумму чека |
| **Return path** | продукт с абонентскими или повторяющимися платежами |
| **Slack adjuster** | дорогой высокомаржинальный (150–300 %) продукт для небольшого процента клиентов или единиц, дающий существенный вклад в прибыль |
| **1 Million $ Product** | продукт всей жизни |
| **BOGO offer** | купи один — получи второй |
| **One Time Offer** | предложение прямо сейчас |
