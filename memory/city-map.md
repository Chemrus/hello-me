# Карта города Фукуок («Карта эпох», вкладка «Сегодня») — фильтры и острова

Владелец 01.11.2026: «на карте основной страницы Фукуока острова показывать отдельно, точками; слева интересные теги — нажал, и лишние достопримечательности убрались: за один день, за три, за семь, с детьми, с парой».

- Код: letfind-wp `themes/letfind/sections/city-epochs-map.php` + `themes/letfind/js/city-epochs-map.js`; поля — `mu-plugins/lf-fit.php`.
- **Панель списка — слева** (была справа).
- **Острова** — группа «🏝 Острова»: бирюзовые точки с подписью, данные из `lfisl_data()` (группы phuquoc/*: Ан Тхой — Хон Том, Гам Ги, Монг Тай, Май Рут; Пиратские — Хон Док; Тхо Тю; Нам Зу — Хон Лон, Хон Мау, Хон Зау; Хон Шон). Мелкие («line») — без точек. Дальние (не Ан Тхой) не тянут масштаб, пока не нажаты «Острова». Карточка острова: что там, как добраться, «без тура», кнопка на страницу группы /vietnam/islands/<группа>/.
- **«Если у вас»: 1 день / 3 дня / Неделя** — поле `lf_fit_days` (1/3/7) у места, заведения, тура. Пусто = неделя. 1 день = юг и закат: Sunset Town, Мост Поцелуев, канатка Хон Том, Бай Сао, тюрьма, пагода Хо Куок, Лонг Бич, Динь Кау, обзорная экскурсия. 3 дня = + север, центр, фермы, острова Ан Тхой.
- **«Подходит»** (галочки, складываются): С детьми, Для пары, Бесплатно, Без толп — поле `lf_fit`; **Закат** ставится сам, если в карточке есть слово «закат». Чип показывается, только если есть хоть одно место с меткой.
- В админке: боковая панель «LetFind: кому подходит (карта города)» у мест, заведений, туров. Первичная разметка 45 мест — migrate `fit-seed:apply` (01.11, по описаниям мест на сайте; заполненное вручную не трогает).
- Фильтры складываются: тип (чипы) + дни + метки. Нет мест — «Под эти условия мест нет — снимите одну из меток».
