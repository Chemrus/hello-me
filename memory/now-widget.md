# Виджет «Сейчас в городе» (акции · события · новые места)

Владелец 25.10.2026: «у нас был виджет с акциями внизу страницы — вернуть»; выбран вариант «наполняется сам, вести всё в одном месте» + «максимально усилить новыми возможностями».
- Старый: `themes/letfind/parts/events-widget.php` («Акции · События · Новые заведения»), только рубрики; брал записи activities/sales с галочкой `events-widget_show` — на 25.10 ни одной (41 с полем, все 0, последние правки 15.08); выключен (`category-hide-events-widget`) в рубриках почти всех городов, включён лишь Фукуок. Проверено режимом info (`.github/deploy/info/events-widget.php`).
- Новый: `mu-plugins/lf-now-widget.php` (ветка claude/now-widget, ждёт «вливай»). Плашка внизу (телефон — над нижним меню #lftb, компьютер — слева, left:72px, правее значка доступности), прячется при плашке cookie; «×» — кружок на 12 ч. Панель: город (select), «🔥 Акции · 📅 События · ✨ Новое», у событий «Сегодня / Неделя»; бейдж, сроки, «⏳ осталось», район (lfpd_pq_short); внизу колесо и конструктор (Фукуок), консьерж, все акции, афиша. «N новых» — по просмотренным на устройстве (`lfnw_seen_<город>`).
- Данные: `lfs_items` (lf-sales), `lfa_events` (неделя) + ежедневные шоу `lfct_config()[город]['shows']`, новые objects/attractions с фото за 45 дней. REST `GET /wp-json/letfind/v1/now?city=` (кэш 2 ч, `lfnw_ver` +1 при сохранении sales/событий/мест). Город — по адресу страницы, иначе последний город (`lf_last_city`), иначе вся страна. Нет в кабинете, корзине, оформлении.
- Старый виджет в category.php не выводится, пока включён новый. Выключить новый: опция `lf_nw = off`.
- События аналитики: nw_open, nw_tab, nw_click, nw_hide.
