# Еда в городах: фильтры «Завтраки · Допоздна · Буфет · Халяль…»

Владелец 05.11.2026: «продолжить дорабатывать виджет по еде в городах — выводить заведения с завтраками, которые работают поздней ночью, буфеты, халяльные и так далее».

## Где
- Вкладка «Еда» на странице города (`lf-city-tabs.php`, `lfct_food`): полоса фильтров над каруселью, под карточкой «🕒 сегодня 07:00–23:00 · открыто», итог «Нашли N мест · списком с картой →» (ведёт в хаб «Еда» с `?f=`).
- Хабы еды (`lf-venue-hubs.php`): «Что важно» теперь на всех страницах еды (/food/, /food/restaurants/, кафе…), не только в подборках по кухне; `?f=breakfast` включает фильтр.
- Признаки — один источник `mu-plugins/lf-food-flags.php` (`lffd_flags`, `lffd_bar`, `lffd_js`).

## Признаки и откуда (только данные, без выдумок)
| Признак | Правило |
|---|---|
| ☀️ Завтраки | тип Google breakfast/brunch_restaurant, «завтрак/бранч» в тексте, по часам открываются ≤ 8:00 хотя бы 4 дня; «подают завтрак» от Google — только если по часам открыты к 9:00 (у Google он бывает и у мест с 10:00) |
| 🦉 Допоздна | по часам закрываются позже 23:00 (на карусели) / с 23:30 в старом правиле хаба заменено общим |
| Открыто сейчас | браузер по часам, время Вьетнама; чип только если часы есть у 60%+ мест |
| 🍱 Буфет | тип buffet_restaurant или «буфет / шведский стол / buffet / all you can eat» в тексте |
| ☪️ Халяль | кухня «Халяль» (lfk_cuisines) или «halal / халяль» в тексте |
| 🥦 Вегетарианские | тип vegetarian/vegan_restaurant или «только вегетарианское / pure veg / вегетарианский ресторан» (не «есть вег. блюда») |
| Детское меню | Google menuForChildren или «детское меню / игровая комната» в тексте |
Вид — по дизайн-системе: «когда» — пунктирные тёплые чипы, «что ищем» — цветные, «условия» — галочки. Несколько выбранных — все сразу (И).

## Данные Google
- Мета: `lf_g_types`, `lf_g_serves` (breakfast, brunch, veg, kids_menu, delivery), `lf_g_serves_at`, часы `lf_hours_week` (если не подтверждены — `lfph_google_may_write`). Текст «Часы работы» не меняем.
- Первый проход 05.11 (`migrate food-google:apply`): 127 из 193 мест, часы — 120; дальше упёрлись в дневную квоту Google.
- Дальше само: WP-Cron `lffd_daily` — до 30 мест в сутки (сначала невзятые, потом старше 60 дней), итог в опции `lffd_last_run`.
- Срез 05.11 (вкладка «Еда»): Фукуок — завтраки 15, допоздна 21, буфет 2, халяль 5, вег 7, детское меню 21; Дананг — 27 / 20 / 6 / 5 / 5 / 21.
