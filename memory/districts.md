# Районы острова Фукуок: один «район» на сайте

Владелец 25.10.2026: «путаница — районы есть, дистрикты отдельно»; «классная фишка, их бы почаще выводить»; «в достопримечательностях показать экскурсии — нужна взаимосвязка»; «квиз пропал».
- **Район = страница района** `/vietnam/phuquoc/<ключ>/` (12 шт., `lf-district.php`: longbeach, onglang, duongdong, baidai, sonasea, marina, meyhomes, anthoi, baikhem, hamninh, inland, ganhdau). Раздел «Районы» острова — `/vietnam/phuquoc/#stay`. Старый гайд `/vietnam/guides/phuquoc-light-guide/` (пост 8370) — только как сравнение, ссылки «Гайд по районам» и вкладки #longbeach/#khem/#onglang переведены на страницы районов (выложено 25.10, main 94fd8c5).
- **Место → район**: `lfpd_target()` (lf-place-district.php): вручную `lfpd_pq_pages()` → по точке `_lf_geo` в рамке района (`bbox` в lfdist_data) → по ключу гайда. 25.10 вручную: Лонг Бич (точка попадала в Сонаси), Вунг Бау → onglang, Винь Дам → hamninh, мыс Онг Дой → anthoi, перечные плантации → inland. Короткие подписи — `lfpd_pq_short()`.
- **Где виден район**: карточка района на странице места; чипы колеса/колоды и находки конструктора (`d` в lfiw_data, кэш `lfiw2_…`); «Районы маршрута» на странице экскурсии; фильтр «Район» в списках мест (lf-venue-hubs, для Фукуока — по страницам районов).
- **Место ↔ экскурсии**: индекс `lftp_index` (lf-tour-places.php) — тур называет место в программе (словарь автоссылок + `lftp_extra_aliases`). 25.10 добавлены Динь Кау, перечная ферма, фабрика рыбного соуса, «Суой Тьань». Наверху места полоска «🚐 Сюда возят N экскурсий · от X $ ↓»; если сюда не возят — «Экскурсии рядом» (туры с остановкой в том же районе). `LFTP_VER` — поднять при правке словаря, индекс пересоберётся сам. Аудит 25.10: экскурсии напрямую у 9 мест из 36 (до правки).
- **Квиз**: «Фукуок за 8 вопросов» `/vietnam/phuquoc/quiz/` (lf-quiz.php) — плитка в «Куда поехать» и строка во вкладке «Районы»; квиз района «за 4 вопроса» — вкладка «Жить» (lfct_where).
- **Правило владельца 25.10:** весь вывод сайта — через район, и относительно «моего района» человека (см. `memory/design-system.md` §2а).
- **«Мой район»** (ветка `claude/my-district`, 25.10, `mu-plugins/lf-my-district.php`): человек выбирает, где живёт → по сайту «🏠 в вашем районе» / «🚶 рядом с вами» / «🚕 ≈ N мин от вас», списки — сначала ближние. Хранение — на устройстве (`lf_my_district`), кэш Cloudflare → всё считается в браузере.
  - Где выбрать: шторка (чип «🏠 Где вы живёте?» в списках заведений), «🏠 Я живу здесь» на странице района, кнопка в итоге обоих квизов (зона → район: wild→ganhdau, east→hamninh, southeast→baikhem, sonasea, inland, north→baidai, center→longbeach, south→anthoi).
  - Где видно: списки заведений Фукуока (район + подпись + фишки на карточке, сначала ближние), чип района в карточке ресторана (шаблон v2), карточка района на странице места, колесо (результат и колода).
  - Минуты: расстояние по прямой от центра моего района × 1,8 + 5, до 5 мин (≈ 33 км/ч; аэропорт → Sunset Town ≈ 35 мин, как на странице трансфера).
  - API для нового вывода: `lfmd_attr( город, район, [lat,lng] )` на элемент + `lfmd_rel()` внутри; `data-lfmd-sort` на список; `lfmd_chip()`; в JS `lfMy.rel()`, `lfMy.label()`, `lfMy.paint()`.
  - **Фишки места:** поле «Фишки (через запятую)» `lf_perks` у заведений и мест — 2–3 коротких, до 40 знаков; видны на карточке. Пишется и через REST (`meta.lf_perks`). 25.10 заполнено 69 мест Фукуока **по нашим же текстам карточек** (`data/perks-phuquoc.csv`) — на проверку владельцу. У ~50 заведений без текста на сайте фишек нет: не выдумываем, нужны данные.
  - 25.10 ещё: виджет «Сейчас» (подпись у акций, событий, новых мест), конструктор поездки (чип + «≈ N мин от дома» в заголовке дня), афиша Фукуока (место · район · подпись), **Дананг** (8 районов заведений из lfd_rules; центры Ан Тхыонг / Ми Кхе→anhai / Хай Чау→center со страниц районов, остальные примерные; «не знаю» → статья 7685), **кабинет** (user option `lf_my_district`, подтягивается на новом устройстве раз за сессию). Ветка `main`, выложено.
  - Не сделано: остальные города; страница экскурсий по районам.
- Дальше (не сделано): фильтр по районам на странице экскурсий; район в карточках афиши.

- 26.10: **гайд по районам собран из сущностей** (владелец: «гайд не обновлён совершенно» → «+»). `/vietnam/guides/phuquoc-light-guide/` (пост 8370) рисует `mu-plugins/lf-guide-pq.php`, текст поста не показывается; копия старого текста — `data/backup/guide-8370-phuquoc-light-guide-20261026.html`.

## Районы других городов (28.10.2026)
Владелец: «районы в Хошимин, Ханой, Нячанг, Вунгтау … подвязку к другим разделам», затем «по вунгтау и куинену тоже», затем «Районы Хойана нужны».
- **Данные** — `mu-plugins/lf-district-cities.php`: `lfdc_cities()` (город → имя, «в …», порядок районов), по функции на город (`lfdc_hcm/hanoi/nhatrang/vungtau/quynhon`), общее — `lfdc_common()`. Сливаются в `lfdist_data()` → работают все блоки `[lf_district]`, «мой район» (lfmd), фишки на заведениях и карточка района на достопримечательностях.
  - Хошимин: district1, district3, binhthanh, thaodien, phumyhung, cholon (названия «бывший 1-й/3-й/7-й район» — после реформы 2025 старые номера отменены, но ими все пользуются).
  - Ханой: oldquarter, hoankiem, badinh, tayho, caugiay. Нячанг: center, north, south, baidai (Бай Зай + Камрань). Вунгтау: baisau, baitruoc, baidau. Куинён: center, ghenhrang, phuongmai. Хойан: oldtown (+ остров Ан Хой), camnam, ricefields (Кам Тяу, Кам Ха, Ча Куэ), anbang, cuadai (+ Кам Тхань).
- **Место → район**: сначала ручная таблица `lfdc_manual()` (id → 'город/ключ' или '' = не в районе), потом точка `_lf_geo` в bbox района. Для Нячанга — правила по адресу в `lf-districts.php` (west → baidai → south → north → center), запасной вариант `lfd_page_district()`.
- **Страницы**: адрес `/vietnam/<город>/<ключ>/`, создаёт миграция `district-pages` (мета `_lfdc_key`). Повторный запуск обновляет только текст — заголовок и SEO не трогает (правим через REST/AIOSEO). id: 19572–19577 Хошимин, 19578–19582 Ханой, 19583–19586 Нячанг, 19587–19589 Вунгтау, 19626–19628 Куинён, 19650–19654 Хойан.
- **Блок «Районы»** на странице города — `lfdc_city_block()` (в lf-city-container; для Нячанга, у которого нет конфига lfcc, — через хук `lf_city_context_container`).
- **Аренда — только словами**, без цифр: источники 2026 расходятся в 2–3 раза.
- Нет фото (заглушка-градиент): Тхао Дьен, Фу Ми Хынг, Бай Сау и Бай Зау (Вунгтау), все три района Куинёна. Чатов по Ханою мало.
- Попутно: у Хошимина были пустые координаты в настройках темы — падала карта на странице города (исправлено миграцией `city-coords`, в JS — защита от пустых).
- **Хойан** (28.10.2026): с 1 июля 2025 года — часть города Дананг; кварталы Hội An (старый город, Кам Нам), Hội An Đông (Кам Тяу, Кыа Дай, Кам Тхань), Hội An Tây (Тан Ан, Тхань Ха, Кам Ан с Ан Бангом, Кам Ха с Ча Куэ), острова Чам — община Tân Hiệp. Чаты — Дананга (отдельных живых по Хойану нет). Такси — заметка «Такси в Дананге» (покрывает Хойан).
  - Честно в тексте: в ноябре 2025 года шторма размыли около 8 км берега от Кыа Дай до Ан Банга; Кыа Дай размывает с 2010-х. Перепроверить к сезону 2027 (идёт проект защиты берега).
  - Старая статья `/cities/all-main-districts-hoian/` (id 4796) — сверху добавлены ссылки на страницы районов (копия до правки — `data/backup/cities-4796-…-20261028.html`).
  - Нет фото: Кам Нам. Без района: The Deck (39 Đào Duy Từ — точка не задана), Шёлковая деревня и мастерская фонарей (без точки), Тхань Ха и острова Чам (вне районов).
