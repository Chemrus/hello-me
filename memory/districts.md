# Районы острова Фукуок: один «район» на сайте

Владелец 25.10.2026: «путаница — районы есть, дистрикты отдельно»; «классная фишка, их бы почаще выводить»; «в достопримечательностях показать экскурсии — нужна взаимосвязка»; «квиз пропал».
- **Район = страница района** `/vietnam/phuquoc/<ключ>/` (12 шт., `lf-district.php`: longbeach, onglang, duongdong, baidai, sonasea, marina, meyhomes, anthoi, baikhem, hamninh, inland, ganhdau). Раздел «Районы» острова — `/vietnam/phuquoc/#stay`. Старый гайд `/vietnam/guides/phuquoc-light-guide/` (пост 8370) — только как сравнение, ссылки «Гайд по районам» и вкладки #longbeach/#khem/#onglang переведены на страницы районов (выложено 25.10, main 94fd8c5).
- **Место → район**: `lfpd_target()` (lf-place-district.php): вручную `lfpd_pq_pages()` → по точке `_lf_geo` в рамке района (`bbox` в lfdist_data) → по ключу гайда. 25.10 вручную: Лонг Бич (точка попадала в Сонаси), Вунг Бау → onglang, Винь Дам → hamninh, мыс Онг Дой → anthoi, перечные плантации → inland. Короткие подписи — `lfpd_pq_short()`.
- **Где виден район**: карточка района на странице места; чипы колеса/колоды и находки конструктора (`d` в lfiw_data, кэш `lfiw2_…`); «Районы маршрута» на странице экскурсии; фильтр «Район» в списках мест (lf-venue-hubs, для Фукуока — по страницам районов).
- **Место ↔ экскурсии**: индекс `lftp_index` (lf-tour-places.php) — тур называет место в программе (словарь автоссылок + `lftp_extra_aliases`). 25.10 добавлены Динь Кау, перечная ферма, фабрика рыбного соуса, «Суой Тьань». Наверху места полоска «🚐 Сюда возят N экскурсий · от X $ ↓»; если сюда не возят — «Экскурсии рядом» (туры с остановкой в том же районе). `LFTP_VER` — поднять при правке словаря, индекс пересоберётся сам. Аудит 25.10: экскурсии напрямую у 9 мест из 36 (до правки).
- **Квиз**: «Фукуок за 8 вопросов» `/vietnam/phuquoc/quiz/` (lf-quiz.php) — плитка в «Куда поехать» и строка во вкладке «Районы»; квиз района «за 4 вопроса» — вкладка «Жить» (lfct_where).
- **Правило владельца 25.10:** весь вывод сайта — через район, и относительно «моего района» человека (см. `memory/design-system.md` §2а).
- **«Мой район» (в работе 25.10):** человек выбирает, где живёт; карточки и списки показывают «🏠 в вашем районе» / «🚕 ≈ N мин от вас», списки — сначала мой район. Кэш Cloudflare → всё на стороне браузера (данные района в карточке, расчёт в JS).
- Дальше (не сделано): фильтр по районам на странице экскурсий; район в карточках афиши.
