# Конструктор поездки («пазл»)

Идея владельца 25.10.2026 (давно хотел): «крутить, листать, конструктор» — человек накидывает карточки (туры, места, пляжи, вкусы, мероприятия), из них собирается «крутой пазл» поездки; можно сохранить в кабинет, прислать друзьям.
- Прототип: `data/trip/trip-prototype.html` (данные Фукуока с колеса на 25.10). Лоток «Ваши находки» → дни × утро/день/вечер, детали пазла сцепляются; тап или перетаскивание; дорога между точками; тур «на весь день» занимает утро+день; «Дособрать за меня»; конфетти, когда день собран; ссылка `#trip=k,k,k|k,k,k` для друзей, WhatsApp/Telegram, консьержу.
- Находки в рабочей версии = «Мой список» колеса (`lf_iw_my`) + «Хочу посетить» кабинета + кнопка «В поездку» на карточках.
- Статус: прототип показан владельцу, ждём решения по вопросам (где живёт, сохранение, друзья).
