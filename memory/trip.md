# Конструктор поездки («пазл»)

Идея владельца 25.10.2026 (давно хотел): «крутить, листать, конструктор» — человек накидывает карточки (туры, места, пляжи, вкусы, мероприятия), из них собирается «крутой пазл» поездки; можно сохранить в кабинет, прислать друзьям.
- Прототип: `data/trip/trip-prototype.html` (данные Фукуока с колеса на 25.10). Лоток «Ваши находки» → дни × утро/день/вечер, детали пазла сцепляются; тап или перетаскивание; дорога между точками; тур «на весь день» занимает утро+день; «Дособрать за меня»; конфетти, когда день собран; ссылка `#trip=k,k,k|k,k,k` для друзей, WhatsApp/Telegram, консьержу.
- Находки в рабочей версии = «Мой список» колеса (`lf_iw_my`) + «Хочу посетить» кабинета + кнопка «В поездку» на карточках.
- 25.10 владелец «+» на план: этап 1 — страница, находки, пазл, ссылка, сохранение в кабинет; этап 2 — совместное редактирование, мероприятия по датам.
- Этап 1 в коде (ветка claude/trip, коммит f3d93a5, ждёт «вливай»): `mu-plugins/lf-trip.php`, страница 19343 `/vietnam/phuquoc/trip/` (черновик, шорткод `[lf_trip city="phuquoc"]`) — опубликовать после выкладки + SEO.
  - Находки: `lf_iw_my` + гостевые `lfCab:<blog>` (want) + «Хочу посетить» аккаунта; пусто — «Для начала — популярное».
  - Черновик на устройстве `lf_trip_cur_phuquoc`, сохранённые `lf_trips_phuquoc`; аккаунт — опция `lf_trips` (до 20), только если `lf_cabinet_can_view` (кабинет сейчас в тихом режиме → обычным людям только устройство). При входе гостевые поездки переносятся сами.
  - Ссылка `#trip=k,k,k|…` (от друга — плашка «Вам прислали поездку»), из кабинета `#trip=…&id=t…`.
  - Кабинет 0.39.0: блок «🧩 Мои поездки» после «Мой день» (v2.php → `lft_cabinet_block`). В колесе — «🧩 Собрать поездку» в «Моём списке».
  - События: trip_place, trip_day_done, trip_auto, trip_save, trip_share, trip_concierge, trip_open_shared.
  - Стенд: блочная тема стенда портит `&&` в скриптах контента (wptexturize) — живой сайт (классическая тема) нет; тест конструктора — через отдельный PHP-файл с do_shortcode.
