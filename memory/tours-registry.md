# Реестр экскурсий и билетов

Владелец 02.11.2026: «разобраться с экскурсиями: где проседаем, где мало описания — реестр, чтобы удобно понимать; билеты — отдельно».

## Где и как
- Админка → Экскурсии → **«📊 Реестр»** (`mu-plugins/lf-tour-registry.php`, letfind-wp). Считает сам, кэш час, сброс при сохранении тура; «Пересчитать сейчас», «⬇ Выгрузить CSV».
- 13 пунктов (вес): фото 10, текст 15, первый экран 5, цена 10, длительность 5, расписание 5, программа 10, входит/не входит 10, взять с собой 5, «Что вас ждёт» 5, вопросы 10, SEO-описание 5, «Кому подходит» 5. Данные тура — как у страницы экскурсии (`lftf_data`).
- Флаги: старый адрес (не `/vietnam/<город>/excursions/`), море без карты (только Фукуок — там карта «Что сейчас в море»), черновик, не обновлялся полгода.
- Заявки: шторка консьержа (с 25.10.2026) по адресу тура или названию в сообщении. WhatsApp/Telegram сайт не видит.
- Вкладка «Билеты»: туры с ссылкой «Купить билет» (сейчас таких 0) + блок «Билеты — закажем за вас» (`lf-tickets.php`, 6 билетов).
- Снять цифры без админки: деплой `info tour-registry` (одна строка на тур).
