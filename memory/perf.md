# Скорость и «мигание» при загрузке

- 25.10.2026 владелец: «на секунду-полторы при загрузке старый вид». Замер (медленный 4G, кадры загрузки): главное — перерисовка шрифта. Страница видна на ~2,8–3,9 с, Gilroy приходит на ~6 с.
- Шрифты темы: `themes/letfind/font/Gilroy-*.woff2` (~26 КБ) есть на сервере, в репозитории нет (и не нужны — не трогаем). На первом экране — 400, 700, 800.
- Сделано (ветка claude/font-preload, ждёт «вливай»): `mu-plugins/lf-font-preload.php` — preload 400/700/800; в `style.css` правило Regular берёт тот же woff2 (раньше лишний .ttf 80 КБ на каждой странице). Проверено подменой на живой странице: шрифты на 1,5 с (до первого показа), картинка та же.
- Ещё видно при загрузке: «Язык» → флаг (скрипт в lf-navigation-targets.php), прочерки в погоде, белое место под фото на главной. Тяжесть: HTML Фукуока ~930 КБ, общий CSS ~570 КБ — отдельная работа.
