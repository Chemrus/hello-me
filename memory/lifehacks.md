# Лайфхаки Вьетнама (/vietnam/lifehacks/)

Владелец 02.11.2026: «лайфхаки с урлом Вьетнам; буду публиковать текстовые и видео-лайфхаки, опрашивать старожилов — классно, прикольно».
- Код: letfind-wp `mu-plugins/lf-lifehacks.php` (префикс `lflh_`; `lfh_` занят lf-history-pq.php), шаблон `mu-plugins/lf-lifehacks/tpl.php` (в подпапке — иначе грузится как mu-плагин).
- Сущность `lf_hack` («Лайфхаки» в админке, значок лампочки). Запись: заголовок = сам лайфхак; текст = подробности; поля: «Суть в одну строку» (lflh_tldr), «Видео» (YouTube и Shorts, VK, Rutube, .mp4 — любая другая ссылка станет кнопкой «Смотреть»), «Тема» (12: деньги, транспорт, жильё, еда, виза, здоровье, связь, покупки, с детьми, безопасность, море, жизнь), «Город», «Кто рассказал», «Кто он», «Сколько лет во Вьетнаме», «Фото рассказчика». Картинка записи — обложка (у YouTube подтягивается сама).
- Раздел: жёлтая шапка, «⭐ Лайфхак дня» (меняется каждый день), фильтры по теме и городу, карточки-стикеры, «💡 Рассказать лайфхак» (шторка заявки, from=lifehacks). Пока записей нет — «Первые лайфхаки уже записываем».
- Запись /vietnam/lifehacks/<адрес>/: стикер с сутью и рассказчиком, плеер, текст, «Скопировать ссылку», «Отправить в Telegram», «Ещё лайфхаки».
- Разметка: раздел — CollectionPage + ItemList; запись — Article с автором-человеком + VideoObject. AIOSEO: заголовок/описание раздела заданы в коде, у записи — из «сути».
- Ссылки: меню «✨ Наш эксклюзив» (первой строкой) и страница /exclusive/.
- Подпись рассказчика — только с его согласия; если имени нет, подпись «Редакция LetFind».
