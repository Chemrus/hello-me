# Ссылки на места и районы (автоссылки)

**Правило владельца (06.11.2026)**, скриншот «Фукуок по месяцам», море «Запад: Лонг Бич, Бай Чыонг, Онг Ланг, Бай Дай»:
«тут нет расшифровок нет ссылок пересмотри весь сайт и нужно нормально сделать».
Значит: **название места или района на сайте — ссылка на его карточку/страницу, а непонятное название — с расшифровкой.**

## Как устроено (letfind-wp, mu-plugins/lf-autolink.php)
- Словарь мест — `lfal_aliases()` (id карточки ⇒ варианты названия, с падежами). Кэш `lfal_places_v2` (12 ч).
  Меняешь варианты — подними номер кэша.
- Словарь районов — `lfal_district_aliases()` ('город/ключ' ⇒ варианты), страница района `/vietnam/<город>/<ключ>/`.
  Если у пляжа/места с тем же именем есть карточка (Лонг Бич, Бай Кхем, Ми Кхе, Ан Банг…), имя ведёт на карточку.
- В текстах записей (the_content) — как раньше: до 5 ссылок.
- **Второй проход по готовой странице** (с 06.11.2026): внутри `<main>` первое упоминание каждого места и района, которого
  на странице ещё нет ссылкой, становится ссылкой с подсказкой (title). До 40 на страницу. Не трогает ссылки, заголовки,
  кнопки, формы, код, меню. Город — по адресу /vietnam/<город>/… или по записи.
  Выключить: `?lfal=off` на странице, опция `lf_autolink_page = off` — на всём сайте.
- Для вкладок (каждый месяц — свой экран) — `lfal_link( $html, $city )` на каждый кусок; для строки текста — `lfal_link_names( $text, $city )`.
  Город может быть списком: побережье Дананга — `array( 'danang', 'hoian' )`.

## Где уже сделано
- «Город по месяцам» (lf-months.php): у каждого берега — подпись + расшифровка (`coasts[][3]`), ссылки в каждом месяце.
  «Бай Чыонг» = Лонг Бич (Bãi Trường) — это один пляж, раньше был записан как второй.
- Живой блок моря (lf-sea.php): названия пляжей ссылками (поле `bh` в /wp-json/letfind/v1/sea).
- Карточка заведения в списках (lf-venue-hubs.php): «📍 район» ведёт на страницу района, если она есть.
- Аудит: `.github/deploy/info/link-audit.php` (info-режим) — сколько названий на главных страницах ещё стоят текстом.
  06.11.2026 до правки: 1087 на 13 страницах.
