# Концепция работы LetFind с ресторанами (владелец, 05.11.2026)

Сжатая запись текста владельца; формулировки-принципы — дословно.

## Первый этап
Активно выходить к ресторанам во Вьетнаме и подключать их. Для каждого — полноценная карточка: название, описание, адрес, часы, контакты, меню, блюда, фото, особенности, условия для семей, способы оплаты, языки, филиалы, специальные предложения.
Задача — **не сделать ещё один каталог, который ресторану придётся отдельно поддерживать**. Мы сами собираем максимум из открытых источников, делаем черновик и приходим не с «Заполните анкету на 40 вопросов», а с **«Мы уже подготовили вашу страницу. Посмотрите, всё ли правильно, и дополните только то, чего не хватает»**. Размещение может быть бесплатным: чем лучше база, тем лучше работают подборки, поиск, Telegram, виджеты, рекомендации.

## Главная идея
**Ресторан должен один раз рассказать о себе, а дальше мы должны максимально снять с него работу по поддержанию и распространению этой информации.**
Одно изменение в реальном мире (например, часы) сейчас порождает десять цифровых обязанностей: Google Business Profile, свой сайт, каталоги, LetFind, партнёры, виджеты, посты. Ресторан сообщает один факт («С пятницы работаем до 01:00») → система показывает «Изменение часов работы. Было 11:00–23:00, стало 11:00–01:00, с пятницы. Обновить: ✓ Google ✓ LetFind ✓ виджеты ✓ партнёрские ресурсы [Подтвердить]».

## Четыре уровня
1. **Убрать повторный ввод** — сообщил один раз → используется во всех каналах (филиалы, часы, контакты, сайт, меню, блюда, услуги, условия, акции, события).
2. **Убрать ручную упаковку** — «У нас появился brunch по выходным» → система готовит обновление карточки, описание, Telegram-пост, текст для соцсетей, спецпредложение, блок для подборки, FAQ, переводы, рекламные варианты, информацию для блогеров.
3. **Убрать ручную дистрибуцию** — система знает подключённые каналы (Google Business Profile, LetFind, Telegram, виджеты, партнёрские сайты, подборки, гиды, блогеры, рекламные площадки) и связывает с ними изменение.
4. **Убрать необходимость придумывать поводы** — система знает праздники и фестивали (вьетнамские и стран гостей), аудиторию, город, кухню, формат, предложения и сама говорит: «Через 14 дней праздник X. Видим хороший повод» → например Couple Dinner Set — 1 290 000 VND, готовы: предложение для страницы, Telegram-пост, виджет, RU и EN версии, варианты для партнёров. Владельцу: **[Принять] [Изменить] [Пропустить]**.

## Google Business Profile — один из главных каналов
Ресторан один раз авторизует доступ; LetFind связывает объект с его профилем и отправляет изменения, которые позволяет API и на которые есть разрешение: название, телефоны, сайт, категории, адрес, обычные, праздничные и дополнительные часы, зона обслуживания, описание, услуги, статус работы, атрибуты. Фото, публикации, меню и отзывы — отдельные механизмы, подключаются постепенно.
Подключение: вместо формы «Название? Адрес? Телефон?» — **«Подключите свою Google-карточку»** → «Основное мы уже собрали. Проверьте и добавьте то, чего обычно нет в Google» (ключевые блюда, особенности меню, кому подходит, дети, языки, оплата, бронирование, факты, предложения, мероприятия, FAQ).
Разделение: **GOOGLE** — базовая публичная информация (название, адрес, телефон, часы, сайт, категория); **LETFIND** — глубокая структурированная (блюда, сценарии, аудитории, языки, дети, платежи, особенности, предложения, события, праздники, live); **DISTRIBUTION ENGINE** — распространение (Google, LetFind, Telegram, виджеты, партнёрские порталы, блогеры, реклама).

## Принципы
- **Система сама думает и готовит → человек принимает решение → система исполняет.** Не бесконтрольный автопилот.
- **Telegram — главный простой пульт ресторана**: «Теперь закрываемся в 00:30» → «Было 23:00, станет 00:30. Обновить ✓… [Подтвердить]». Голосовое: «Добавили brunch по выходным с 10 до 14, 450 тысяч» → AI разбирает, показывает, после подтверждения запускает.
- **Партнёрские ресурсы забирают информацию из LetFind** (виджеты, данные): «Акции ресторанов на этой неделе», «Предложения к Lunar New Year», «Что происходит на Фукуоке сегодня». LetFind — источник актуальной структурированной информации для других площадок.
- **Статус синхронизации**: 🟢 LetFind — обновлено · 🟢 Widget · 🟡 Google — отправлено, ждём публичного обновления · 🟢 Partner A; расхождение — 🔴 Google — часы отличаются. **Следим, чтобы цифровая информация о бизнесе не разъезжалась.**
- Если канал нельзя обновить автоматически — готовим текст, значение, описание, фото и ссылку на нужный раздел; владельцу остаётся последний шаг.

## Предложение ресторану — три уровня
1. **Расскажите о своём ресторане один раз.**
2. **Когда что-то изменилось — скажите об этом один раз.**
3. **Если мы видим повод для продвижения — мы сами его вам покажем.** (Принять / изменить / пропустить.)

**Бизнес больше не должен быть медиа-компанией.** Зеркало: пользователь не ищет — говорит, что нужно; бизнес не бегает по площадкам — говорит, что произошло и что может предложить. LetFind соединяет спрос и предложение. Карточки — не конечный продукт, а **входная точка** в систему.
