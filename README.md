# hello-me

Простой консольный скрипт на Python.

## Запуск

```bash
python app.py
```
## Публикация на letfind.me (`wp.py`)

Скрипт создаёт и обновляет записи на сайте через WordPress REST API. Нужен только Python 3, сторонние пакеты не требуются.

### Доступ

1. В админке WordPress откройте **Пользователи → Профиль → Пароли приложений**, введите название (например, `hello-me`) и нажмите **Добавить**. Скопируйте пароль — он показывается один раз.
2. Задайте переменные окружения:

   | Переменная        | Значение                                              |
   |-------------------|-------------------------------------------------------|
   | `WP_USER`         | логин пользователя WordPress: поле «Имя пользователя» в профиле (не email и не название пароля приложения) |
   | `WP_APP_PASSWORD` | пароль приложения из шага 1 (можно вместе с пробелами) |
   | `WP_URL`          | необязательно, по умолчанию `https://letfind.me`      |

   Пароль не храните в репозитории. Переменные задаются в настройках окружения Claude Code; после изменения откройте новую сессию — текущая видит старые значения.

3. Проверьте подключение: `python wp.py check`

### Команды

```bash
python wp.py types                                   # типы записей (articles, news, guides, ...)
python wp.py list --type articles -n 5               # последние записи
python wp.py get 123 --type articles                 # запись целиком в JSON
python wp.py create --type articles --title "Заголовок" --content-file post.html   # черновик
python wp.py create --type news --title "..." --content "<p>...</p>" --status publish
python wp.py update 123 --type articles --title "Новый заголовок" --status publish
```

Новые записи по умолчанию создаются черновиками (`draft`).

### Если что-то не работает

- **`rest_forbidden` при `check`**: этот сайт так отвечает и на неверный логин или пароль. Сначала проверьте, что в `WP_USER` логин из поля «Имя пользователя» в профиле, а пароль приложения создан у этого же пользователя.
- **`rest_forbidden` при верных логине и пароле**: хостинг не передаёт заголовок `Authorization` в WordPress. Добавьте в начало `.htaccess` сайта:

  ```apache
  SetEnvIf Authorization "(.*)" HTTP_AUTHORIZATION=$1
  ```

- **`SiteGround captcha`**: антибот-защита хостинга. Скрипт сам повторяет такие запросы. Если ошибка не проходит, разрешите доступ к `/wp-json/` в SiteGround Site Tools → Security.
